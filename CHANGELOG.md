## 0.1.0 - 2026-10-12

Commit `37b8fe39be6a`; release record `pub:sha2-256:75xyuphpy3av32tshpm5rhcgimd7mar7z35hbdleibjppgwwq5pa`.

pubunit's first release: exact, kind-aware checking and conversion of UCUM units, built on ucum-units, with trays, currencies and CO2 equivalents declared as base dimensions and quantity kinds checked by declaration, never inferred.

### Added
- pubunit: parse UCUM expressions into a public tree, and reduce them to a dimension and an exact rational factor, with UCUM's values read from the essence file the pinned ucum-units 0.1.0 bundles
- Exact conversion between commensurable units, temperatures with an offset included when they stand alone; special and arbitrary units are refused
- Base dimensions, units and quantity kinds declared as data, in a serde definitions format: {tray}, {batch}, [EUR] and {CO2e} are dimensions, and a unit is checked against its declared kind
- The pubunit command: parse, validate, reduce, convert, check, kinds and ucum
- The dimension algebra (Dimension, Reduced) and the parse tree (Term) are public, for symbolic computation

### Internal
- Brought pubunit to the Rust crate standard before its first release: TESTING.md and the doc-coverage guard, the _documentation module on docs.rs, test vectors from NIST SP 811 and the SI Brochure, property tests, a shorter README with the definitions format in the crate docs, Dimension::to_ucum for a valid UCUM form of a dimension, and this project's own cargo-vet audit of ucum-units 0.1.0 in place of its exemption
- The _documentation module allows brackets in its prose, so a changelog that names [EUR] no longer fails the doc build
